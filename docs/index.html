qtrace

strace for the QNX OS 8.0 microkernel: every kernel call of a process, the server behind every message, and why it waited.

Codelab: What Is My QNX Program Waiting For? Trace message passing on QNX 8.0 with TraceEvent() and libtraceparser, and see how long each message queued, how long the server worked and at which priority. Example report: sh -c "ls /proc/boot | wc -l" The HTML report qtrace wrote on QNX 8.0 in QEMU: a timeline of the client threads, the server threads that served them and the messages between them.
